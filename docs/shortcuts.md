# Shortcuts

## Global

Active in any browser window; change them at `chrome://extensions/shortcuts`.

| Shortcut | Action |
|----------|--------|
| Alt+A | Open the side panel; when it is open, put keyboard focus back into it, for instance after Enter activated a tab. With the setting *Side panel shortcut closes an open panel* on, a press on an open panel closes it instead |
| Alt+Y | Close the side panel |
| Alt+Q | Open the list in a popup window, or bring it to the front. With the setting *Popup shortcut closes when focused* on, a second press closes it |
| Alt+S | Open the quick search; a second press while it is focused closes it |

## Tabs view

Active while the side panel or the popup window has focus.

| Key | Action |
|-----|--------|
| Arrow Up / Down | Move the cursor. In the popup window each tab is activated as the cursor reaches it; in the side panel only the cursor moves. Arrow Up on the first tab moves into the search field |
| Home / End | Jump to the first / last tab |
| Enter | Activate the tab under the cursor and focus its window; a search is cleared |
| Shift + Arrow Up / Down | Extend the selection to a contiguous range |
| / | Focus the search field; Enter opens the first match, Arrow Down moves onto it in the list |
| W | Close the tab under the cursor, or all selected tabs |
| Space | Rename the tab under the cursor, or name a new group from the selected tabs |
| S | Switch to the Sessions view |
| Escape | Clear the search; in the popup window, close it |

Mouse: click activates, ctrl-click toggles the selection, shift-click selects a range, right-click opens the menu.

## Sessions view

| Key | Action |
|-----|--------|
| Arrow Up / Down | Move the cursor |
| Enter | Open the session, or jump to its group when it is already open |
| T | Switch to the Tabs view |

## Quick search

| Key | Action |
|-----|--------|
| Typing | Fuzzy search across tabs and sessions |
| Arrow Up / Down | Move through the results |
| Enter | Activate the result and close |
| Escape, or losing focus | Close |
